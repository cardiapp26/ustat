# pandas, numpy, scipy, statsmodels, scikit-learn and patsy are pinned to the
# versions Pyodide 0.27.7 ships, NOT to the newest releases. uSTAT runs the
# same statistics code in two runtimes -- this server, and CPython compiled to
# WebAssembly in the browser -- and a version difference between them means one
# analysis can return two different numbers with nothing on screen to say which
# one the reader is looking at. Raising any of these is therefore a decision
# about the browser runtime, not a routine dependency bump: check the target
# release's pyodide-lock.json first and move both sides together.
#
# What the lock costs: scipy 1.15 improved the accuracy of the noncentral t and
# F distributions, so power analysis sits a few parts per million further from
# R's pwr than it would on 1.15. See tests/test_power_vs_r.py, which states the
# tolerance that buys.
